### MVP(minimum viable product)

## What is scoutify? 
Scoutify is a web application in which user's can scrap business contact information from online websites.

## What is scoutify v1
Scoutify v1 is the 1st version of scoutify, in which user give list of one or more URLs  as Input,
and scoutify will scrape the contact information from these sites and return the contact information.

## User Input
Inside scoutify(v1) web application, users input the list of Business/other Websites URLs

## Process
Scoutify scrape the contact information from the given URL's and return the contact information

## Output
Scoutify returns
- Business Name
- Phone number
- email
- physical address
- Website URL
- Social media links

## Export
Users can export their results as CSV file by making use of export option.

## Storage
Scoutify stores the result generated in the database.
And its accessable only by that particular user.

## What is not covered in v1?
Currently in V1, Users can only get the scraped information only by giving URLs manualy
to the application.
- currently AI URL collection is not implemented
- currently Keyword Search query based URL collection system is not implemented
- Search engine search based URL collection system is not implemented.
