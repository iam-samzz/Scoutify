# Requirements

## Functional Requirements

- FR0  The user should able to enter single URl, multiple url, URL's in csv file
- FR1  The system validate the URL
- FR2  The system skip scraping the website if no information can be fetched.
- FR3  The application returns all the contact details seperatly for the given URL's
- FR4  The application have authentication fetures.
- FR5  The application stores the user's scrape history in database
- FR6  The user can login any time and get their scraped data
- FR7  The user can export their results.

## Non-Functional Requirements

- NFR0 The applicatton should not crash when a website link is not working properly.
- NFR1 User's personl data must be encrypted.
- NFR2 The scraping process should not stop when one or more websites are crashing.
- NRF3 Duplicate URL's should be handled.
- NRF4 The application should handle INvalid URLs
