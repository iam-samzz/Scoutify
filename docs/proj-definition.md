# Project Definition

## Problem
Online users, Freelancers, JobSeekers, Business Opportunity seekers and General internet users are facing
Reluctant feel for searching contact informations one by one from each and every business sites one by one.
Usually non tech users , just search in search engine and get a list of URL's and they start searching for Contact info
in each sites. Users feel overwhelmed in this process of searching.

## Target Users
- Freelancers who are seeking for clients
- Business Opportunity seekers
- Job Seekers
- online users
- startup founders
- B2B sales representatives
- Recruiters & Talent Sourcers
- Market Researchers & Analysts

## Input
- url
- url list(csv)
- multiple url's

## Processing
Scoutify get one or more number of URL from the user and return the list of contact information
which is scraped from every websites.

## What scoutify returns?
Returns the below details if they are available
- contact number
- source website
- address
- email

## Limitations
Currently in version 1 (V1) ,scoutify expects user's to enter the URL
manually rather then query search, and There may be some data missing when
scraping through the websites.
